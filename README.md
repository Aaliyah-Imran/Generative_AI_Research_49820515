# Generative AI Research

## Project Overview

This repository contains research materials for the project
"Using Generative AI Tools - Boon or Bane."

## Repository Structure

- `01_Literature_Review/`
  - Journal articles, conference papers, books and news articles.

- `02_Quantitative_Analysis/`
  - Survey data, survey questions, analysis scripts and quantitative reports.

- `03_Qualitative_Analysis/`
  - Interview protocols, transcripts, analysis files and visualisations.

- `04_Drafts_and_Reports/`
  - Research proposals, conference papers and final reports.

- `05_Additional_Materials/`
  - Information sheets, photographs and other supporting materials.

- `Project_logbook.txt`
  - Records changes and progress throughout the research project.

## Navigation

Files are grouped according to research activity and data type.
Folder names use numerical prefixes so that the major project sections
appear in a consistent order.

## Contribution Guidelines

1. Synchronise your local repository with the latest `main` branch before beginning work.
2. Create a new descriptive branch for each change.
3. Use clear and meaningful commit messages.
4. Push the branch to your fork.
5. Submit a pull request to the main repository.
6. Review changes before merging.
7. Resolve merge conflicts carefully before completing a merge.

## Data Management

Sensitive or identifiable research data should only be stored in approved
secure research systems and should not be placed in a public GitHub repository.
Only non-sensitive or de-identified example data is included here.
